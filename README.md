# AI-Powered PDF Analyzer

A full-stack AI-powered web application that analyzes PDF documents using NLP and machine learning techniques, providing automated summarization, sentiment analysis, and topic detection with API integration.

## Features

- PDF text extraction  
- AI-based text summarization   
- Sentence-level sentiment analysis (Positive, Negative, Neutral)  
- Topic detection using machine learning  
- Real-time processing with error handling  
- User-friendly frontend interface  

## Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: FastAPI  
- NLP / ML: Hugging Face Transformers(FinBERT), BERTopic, SentenceTransformers  
- PDF Processing: PyMuPDF  
- LLM API: Groq (using LLaMA 3)
